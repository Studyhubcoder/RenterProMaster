# Rent Manager - Separated v12

Structure:
- frontend/index.html  -> complete frontend in one file
- backend/server.js    -> complete backend in one file
- package.json         -> npm configuration only

No .env file is required.
MongoDB URI is directly inside backend/server.js.

MongoDB:
mongodb://127.0.0.1:27017/rent_manager

Run:
1. Open this folder in VS Code.
2. Run: npm install
3. Make sure MongoDB Server is running.
4. Run: npm run dev
5. Open: http://localhost:3000
